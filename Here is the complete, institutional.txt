Here is the complete, institutional-grade algorithmic framework engineered specifically to evaluate **Domestic Indian Equity Mutual Funds**. 

While the core philosophy remains identical to the International framework, the **thresholds for Cost (TER) and Downside Mitigation are strictly tightened**. Domestic funds do not suffer from the dual-layer FoF fee structure, and domestic large/mid-cap indices inherently carry lower baseline volatility than global tech indices. Therefore, the algorithm demands higher efficiency and lower fees from domestic fund managers.

---

### ⚙️ Phase 1: Data Ingestion & Pre-Processing

**Variables Mapped from Domestic CSV:**
*   `roll_3y` = `3Y Avg Annual Rolling Return` *(Note: Watch for trailing spaces in CSV headers)*
*   `cagr_5y` = `CAGR 5Y`
*   `sharpe` = `Sharpe Ratio`
*   `vol` = `Volatility`
*   `alpha` = `Alpha`
*   `ter` = `Expense Ratio`
*   `aum` = `AUM` (in Cr)

**Edge-Case Handling:**
*   **The "Zero" Trap:** New funds (e.g., Tata Capital Markets Index) have `0` in the `CAGR 5Y` column.
*   **Algorithm Rule:** `IF cagr_5y == 0 THEN flag as "Missing_Long_Term_Data"`. Assign a fixed 15-point penalty for Consistency.
*   **The Direct vs. Regular Plan Trap:** The algorithm *assumes* the ingestion of **Direct Plan** TERs. If Regular Plan TERs are fed into Module 5, the fund will be unfairly rejected. 

---

### 🧮 Phase 2: The 100-Point Domestic Scoring Engine

#### Module 1: Rolling Return Consistency (Max 30 Points)
*Objective: Penalize point-to-point CAGR anomalies and reward continuous momentum.*
*(Identical to International)*

```text
IF cagr_5y == 0:
    Score_1 = 15  // Penalty for missing long-term cycle data
ELSE:
    Gap = roll_3y - cagr_5y
    IF Gap > 0:
        Score_1 = 30  // Accelerating momentum
    ELSE IF Gap >= -5:
        Score_1 = 20  // Stable/Slight cooling
    ELSE IF Gap >= -10:
        Score_1 = 10  // Moderate cooling
    ELSE:
        Score_1 = 5   // Sharp decline/Mean reversion risk
```

#### Module 2: Risk-Adjusted Efficiency (Max 25 Points)
*Objective: Measure return generated per unit of total risk taken.*
*(Identical to International)*

```text
IF sharpe > 1.0:
    Score_2 = 25  // Institutional grade
ELSE IF sharpe >= 0.8:
    Score_2 = 15  // Strong retail grade
ELSE:
    Score_2 = 5   // Poor risk-adjusted efficiency
```

#### Module 3: Downside Risk Mitigation (Max 20 Points)
*Objective: Proxy for downside capture. Tightened for domestic equity baselines.*

```text
IF (vol < 20 AND sharpe > 1.0):
    Score_3 = 20  // Elite downside protection (e.g., HSBC Midcap)
ELSE IF (vol < 25 AND sharpe >= 0.8):
    Score_3 = 12  // Acceptable domestic protection (e.g., DSP TIGER)
ELSE:
    Score_3 = 5   // High uncompensated volatility (Fails institutional threshold)
```

#### Module 4: True Alpha Generation (Max 15 Points)
*Objective: Isolate the fund manager's actual skill from baseline Nifty/BSE beta.*
*(Identical to International)*

```text
IF alpha > 5.0:
    Score_4 = 15  // Exceptional manager skill
ELSE IF alpha >= 2.0:
    Score_4 = 10  // Good manager skill
ELSE:
    Score_4 = 5   // No real skill / Pure beta
```

#### Module 5: Cost & Concentration Drag (Max 10 Points)
*Objective: Penalize excessive fees. **Strictly tightened for domestic funds** since there is no FoF dual-layer fee excuse.*

```text
IF (ter < 0.8 AND vol < 20):
    Score_5 = 10  // Elite (Rewards Index funds & highly efficient active funds)
ELSE IF (ter < 1.2 AND vol < 25):
    Score_5 = 5   // Acceptable (Standard active domestic funds)
ELSE:
    Score_5 = 0   // Rejected (TER >= 1.2% or Vol >= 25% is unacceptable domestically)
```

#### Final Aggregation
```text
Total_Score = Score_1 + Score_2 + Score_3 + Score_4 + Score_5
```

### 💻 Phase 3: Python Implementation (Pandas)

Here is the exact vectorized Python code to run your domestic CSV through the institutional engine.

```python
import pandas as pd
import numpy as np

# Load data (Ensure you are using the Direct Plan dataset)
df = pd.read_csv('Domestic_Equity_Funds_Direct.csv')

# Clean column names (remove trailing spaces if present in CSV)
df.columns = df.columns.str.strip()

# 1. Rolling Consistency (30 pts)
gap = df['3Y Avg Annual Rolling Return'] - df['CAGR 5Y']
df['Score_1'] = np.select(
    [df['CAGR 5Y'] == 0, gap > 0, gap >= -5, gap >= -10],
    [15, 30, 20, 10], 
    default=5
)

# 2. Risk-Adjusted Efficiency (25 pts)
df['Score_2'] = np.select(
    [df['Sharpe Ratio'] > 1.0, df['Sharpe Ratio'] >= 0.8],
    [25, 15], 
    default=5
)

# 3. Downside Mitigation (20 pts) - Domestic Thresholds
df['Score_3'] = np.select(
    [(df['Volatility'] < 20) & (df['Sharpe Ratio'] > 1.0), 
     (df['Volatility'] < 25) & (df['Sharpe Ratio'] >= 0.8)],
    [20, 12], 
    default=5
)

# 4. True Alpha (15 pts)
df['Score_4'] = np.select(
    [df['Alpha'] > 5.0, df['Alpha'] >= 2.0],
    [15, 10], 
    default=5
)

# 5. Cost & Concentration (10 pts) - STRICT Domestic Thresholds
df['Score_5'] = np.select(
    [(df['Expense Ratio'] < 0.8) & (df['Volatility'] < 20),
     (df['Expense Ratio'] < 1.2) & (df['Volatility'] < 25)],
    [10, 5], 
    default=0
)

# Final Score
df['Total_Score'] = df['Score_1'] + df['Score_2'] + df['Score_3'] + df['Score_4'] + df['Score_5']

# Sort and Display
df = df.sort_values('Total_Score', ascending=False)
print(df[['Name', 'Sub Category', 'Total_Score', 'Score_1', 'Score_2', 'Score_3', 'Score_4', 'Score_5']].head(10))
```
